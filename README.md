# Demo

Demo is a starter restaurant website built with React and Vite. The homepage is already structured around immersive 360-degree table previews.

## Run locally

```bash
npm install
npm run dev
```

The Vite dev server will print a localhost URL, usually `http://localhost:5173/`.

## Add your 360 table photos

Place equirectangular panorama images in:

- `public/panoramas/table-garden.jpg`
- `public/panoramas/table-chef.jpg`
- `public/panoramas/table-terrace.jpg`

If a file is missing, the app shows a helpful placeholder instead of breaking.
